# نگاشت نیازمندی‌ها و وضعیت پذیرش

| معیار سند | وضعیت این نسخه | شرح |
|---|---|---|

| اسکن بارکد، یکتایی و بارکد داخلی | انجام‌شده | جست‌وجوی بارکد مثل ورودی صفحه‌کلید؛ کلید یکتا؛ بارکد داخلی `AP-1405-####` و برچسب چاپی |

| ثابت‌ماندن فاکتور قدیمی بعد از ویرایش قیمت | انجام‌شده | snapshot قیمت، هزینه، نام و بارکد در ردیف فاکتور و سابقه تغییر قیمت |

| دو انبار و حساب تعمیرگاه | انجام‌شده | انتقال داخلی، حفظ لایه هزینه، گزینه ثبت بدهکار/بستانکار در دفتر تعمیرگاه |

## پیش‌نیازهای پیش از استفاده واقعی

1. پیاده‌سازی/انتقال لایه اپلیکیشن به Laravel 12، PHP 8.3 و MySQL/MariaDB طبق سند؛ این نسخه اجرایی فعلی FastAPI/SQLite است.
2. انتقال نشست‌ها به Laravel Sanctum، ذخیره امن/چرخش توکن‌های کانال، HTTPS، محدودسازی brute-force و تنظیم دسترسی VPS.
3. تغییر رمزهای آزمایشی، تعریف حساب‌های واقعی و پاک‌کردن داده نمونه.
4. تمرین بازیابی کامل فایل ZIP روی محیط جداگانه و تعریف نسخه پشتیبان خارج از دستگاه.
5. تست پذیرش با چاپگر HP، بارکدخوان، PDFهای واقعی تأمین‌کنندگان و قواعد دقیق اعتبار/تسویه تعمیرگاه.
